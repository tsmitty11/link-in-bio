# link-in-bio

Thomas Smith's static link-in-bio site, styled from the Figma design with Neue Haas Unica from Adobe Fonts.

- `index.html` — profile, main links, and social profiles.
- `ventures.html` — Hatrack Digital project cards.
- `styles.css` — shared responsive layout and glass styling.
- `images/` — locally stored portrait and social icons exported from Figma.

Preview locally with `python3 -m http.server 5173`, then open http://localhost:5173.
No build step or JavaScript is required for navigation. The Resumé button links to LinkedIn.
